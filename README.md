# Frontend CI/CD demo

Простой React-проект для демонстрации CI/CD. Опубликованная страница показывает
номер коммита, сообщение, ветку и время сборки.

При push в `main` GitHub Actions:

1. устанавливает зависимости;
2. проверяет код;
3. собирает приложение;
4. отправляет папку `dist` на сервер по SSH.

Локальный запуск:

```bash
npm install
npm run dev
```
